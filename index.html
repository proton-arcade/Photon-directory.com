Six sites that live in this folder and never call anybody.

This is the index card drawer for a small collection of downloaded sites: games, a media player, Minecraft, two tools and a search box. Every one of them is a file or two, opened relative to where they sit. Pull the folder off the network and the hub keeps working, because it was never asking for anything.

The listings below are printed, not decorated. A row is a name, what it is for, how heavy it is, and a ringed button that opens it. Nothing here is a landing page for itself.

Kept by hand since the drawer was cut. The only thing on this site that moves is the notice strip above and the index printing itself out — a board that never changes is a decoration.

House rules

How a hub like this stays offline

RuleWhat it costs and what it buys
No CDNsEmulatorJS, React, a font service — all refused. Costs: no free speed. Buys: the hub works in a car with no signal.
Relative linksEvery href is a file next to this one, so the folder can be renamed, moved or zipped without anything breaking.
Installed typeGeorgia and Courier New, both on every machine since forever. Nothing is waited for.
No fetch at bootThe index is typed into js/index-data.js. A file:// open is a second-class citizen on purpose, so we do not make it worse.
Local memoryScores, notes and pins go to localStorage. Clear the site data and it is all gone, which is the point.
One motion eachThe strip scrolls because a notice board changes. The index prints because a directory is looked up. Nothing else moves at you.
