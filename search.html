How it scores a hit

Each word in the box is looked for in the title (12 if it starts the title, 8 if it only appears), the file name (5), the keyword line (7 when it is a whole keyword, 4 inside one) and the blurb (3). A word nothing matches subtracts 2, which is how video flute comes back empty instead of showing you the media player anyway.

Your last eight lookups are kept in localStorage as photon.searches.v1, so this page can offer them back. It is the only thing search remembers.

Misses are useful

When a lookup finds nothing the page prints the word it could not place, and that is the list I work from: a hub that cannot be searched for flac is a hub missing a line about flac. Adding a row means adding one entry to js/index-data.js.
